# Sales KPI Analysis Dashboard

## Project Overview

This project analyzes retail sales data using MySQL and Power BI to identify key business insights related to sales performance, profitability, customers, products, and regional trends.

## Tools Used

* MySQL
* Power BI
* SQL
* Microsoft Excel

## Dataset

* Superstore Sales Dataset
* 9,694+ sales records
* Customer, product, sales, profit, region, and category information

## SQL Analysis Performed

* Total Sales & Profit Analysis
* Regional Performance Analysis
* Category Performance Analysis
* Top Customers Analysis
* Top Products Analysis
* Segment Analysis
* Discount Impact Analysis
* Window Functions (RANK, LAG)
* Month-over-Month Growth Analysis

## Key Insights

* West region generated the highest sales and profit.
* Technology category produced the highest profitability.
* Furniture showed high sales but relatively low profit margins.
* Identified top-performing customers and products.
* Higher discounts negatively impacted profitability.

## Dashboard Features

* KPI Cards (Sales, Profit, Orders, Customers)
* Regional Sales Analysis
* Category Profit Analysis
* Top Products
* Top Customers
* Monthly Sales Trend
* Segment Distribution
* Interactive Filters
